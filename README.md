# AquaStride Academy Website

Website for a swimming academy, made from my Figma mockup for the Introduction to Web Development final output.
Built with plain HTML, CSS and JavaScript.

## Pages

- `index.html` - Home
- `about.html` - About Us
- `programs.html` - Programs
- `schedule.html` - Schedule & Pricing
- `contact.html` - Contact (enrollment form)

## Folders

- `css/style.css` - all the styles (desktop, tablet and mobile)
- `js/main.js` - mobile menu and form message
- `images/` - photos, logo and icons
- `videos/` - video and audio on the About page

## Notes

- Tablet layout is 1024px and below, mobile is 767px and below.
- The form only shows a thank-you message, it does not send the data anywhere yet.
- Video source: Simply Swim.

## Publishing on GitHub Pages

1. Push this folder to the `main` branch of the repository.
2. Go to **Settings > Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
3. After a minute the site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
